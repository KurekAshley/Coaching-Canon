# Kurek Ashley Coaching Canon

## Overview

This repository contains the canonical coaching frameworks, identity architectures, and teaching systems of Kurek Ashley.

All material is derived from live coaching, workshops, and transcript-based extraction.

This is not a content library.

It is a structured body of intellectual property designed for:

- Human clarity
- Machine readability
- Long-term authority indexing

---

## Structure

The repository is organized into:

### Wiki (Primary System)
- One file per framework
- Independent architecture per system
- No compression across frameworks

### Canonical Index
- System-level map of all frameworks
- Grouped by function

## Scope

- Coaching frameworks

- Frequency and creation models
- Decision and execution systems
- Teaching methodologies

## Status
